# Frontend

Aplicacao Next.js 14 do Kwak Finance.

## Scripts

Use os scripts da raiz `projeto/` sempre que possivel:

```bash
pnpm run dev
pnpm run build
pnpm run lint
pnpm run typecheck
```

Este pacote deve conter apenas codigo de UI, App Router, componentes, estilos e chamadas HTTP. Regras de dominio, Prisma, IA e segredos ficam em `../backend`.
