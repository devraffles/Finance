# Task 03 - Schema do Banco PostgreSQL

## Objetivo

Implementar `backend/prisma/schema.prisma` com os modelos principais do Financas 360 usando PostgreSQL.

## Arquivo

- `projeto/backend/prisma/schema.prisma`

## Regras

- Datas devem usar `DateTime @default(now())` onde aplicavel.
- Use `@map` e `@@map` para nomes em snake_case quando fizer sentido.
- Use `Float` para valores monetarios conforme prompt.
- Mantenha receitas positivas e despesas negativas em `Transacao.valor`.
- Toda entidade de dominio pertencente ao usuario deve ter `userId`.

## Enums obrigatorios

```prisma
enum TipoConta     { CORRENTE POUPANCA CARTAO INVESTIMENTO CAIXA OUTRO }
enum PerfilConta   { PF PJ }
enum TipoTransacao { RECEITA DESPESA TRANSFERENCIA }
enum TipoInvest    { ACAO FII RENDA_FIXA CRIPTO FUNDO TESOURO PREVIDENCIA OUTRO }
enum TipoAporte    { COMPRA VENDA DIVIDENDO RESGATE JUROS }
enum TipoEmpresa   { MEI ME EPP LTDA SA AUTONOMO }
```

## Modelos obrigatorios

| Modelo | Campos-chave |
| --- | --- |
| `User` | id, email unique, name, password, createdAt, relacoes |
| `Conta` | id, nome, tipo, perfil, instituicao, saldo, cor, ativo, empresaId?, userId, timestamps |
| `Transacao` | id, descricao, valor, tipo, categoria, subcategoria?, data, competencia, contaId, perfil, empresaId?, tags, observacao?, recorrente, categorizadoPorIA, userId, timestamps |
| `Investimento` | id, nome, tipo, corretora, quantidade, precoMedio, precoAtual, valorInvestido, valorAtual, rentabilidade, dataAporte, vencimento?, indexador?, percentualIndice?, dividendos, userId, aportes, timestamps |
| `Aporte` | id, investimentoId, valor, quantidade?, preco, data, tipo, createdAt |
| `Meta` | id, titulo, descricao?, valorAlvo, valorAtual, prazo, categoria, cor, concluida, userId, timestamps |
| `Empresa` | id, nome, cnpj, tipo, ativa, userId, contas, transacoes, timestamps |

## Comandos locais

Apos escrever o schema, nao use `db push` como caminho principal. Para desenvolvimento local fora do Docker:

```bash
pnpm exec prisma migrate dev --name init
pnpm exec prisma generate
```
