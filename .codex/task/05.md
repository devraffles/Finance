# Task 05 - Infraestrutura Base de Aplicacao

## Objetivo

Consolidar Prisma, Better Auth, Gemini, utilitarios e tipos de dominio para
servirem como fundacao segura para as telas e APIs do Kwak Finance.

## Arquivos principais

- `projeto/backend/src/lib/prisma.ts`
- `projeto/backend/src/lib/auth.ts`
- `projeto/backend/src/lib/gemini.ts`
- `projeto/frontend/src/lib/utils.ts`
- `projeto/backend/src/types/financas.ts`
- `projeto/frontend/src/types/financas.ts`

## Autenticacao

- Usar Better Auth com adaptador Prisma/PostgreSQL e email/senha.
- Validar configuracao com Zod e nunca expor segredos no client.
- Exportar `auth` e `getSession(headers)` para uso exclusivo do servidor.
- Manter o adapter fino em `frontend/src/app/api/auth/[...all]/route.ts`.
- A sessao deve disponibilizar `user.id` para que APIs possam aplicar ownership.

## Prisma

- Exportar singleton `PrismaClient` seguro para hot reload do Next.js.
- Usar logs reduzidos em producao e nao instanciar varios clientes em desenvolvimento.

## Gemini

Exportar `callGemini`, `categorizarTransacoes` e `gerarInsights`.

- Categorizacao usa `gemini-2.5-flash`; insights usam `gemini-2.5-pro`.
- A chamada deve expirar em 30 segundos com `AbortController`.
- Ausencia de `GOOGLE_GENERATIVE_AI_API_KEY` deve resultar em resposta controlada,
  sem derrubar a aplicacao.
- Respostas estruturadas de IA devem ser validadas por Zod antes do uso.

## Utilitarios e tipos

- `formatCurrency` usa `pt-BR` e `R$`.
- `formatDate` usa Day.js e exibe `dd/MM/yyyy`.
- Manter `cn`, `formatPercent`, `calcularVariacao`, `gerarCorAleatoria` e `slugify`.
- `parseCSVNubank` fica no frontend, retorna um contrato seguro de UI e normaliza
  data para `YYYY-MM-DD` e valores brasileiros. O backend continua validando o
  payload com Zod antes de persistir.
- Manter os tipos de dominio no backend e contratos de apresentacao no frontend;
  componentes de UI nao importam Prisma, IA ou servicos do backend.

## Testes e aceite

- Cobrir formatadores, parser CSV, configuracao de auth e falha controlada sem
  chave Gemini com Vitest.
- Manter teste E2E de login e validar o fluxo com o usuario seed quando o banco
  estiver disponivel.
- Executar `pnpm test`, `pnpm run lint`, `pnpm run format:check`,
  `pnpm run typecheck` e `pnpm run build`.
- Nenhum `any`, segredo exposto ou dado de outro usuario.
