# Task 09 - Modulo de Contas

## Objetivo

Implementar `/contas` com resumo financeiro, grid de contas e CRUD por modal.

## Tela

Rota:

- `projeto/frontend/src/app/(app)/contas/page.tsx`

## Funcionalidades

- Resumo de totais no topo:
  - Total em Conta Corrente.
  - Total Poupanca.
  - Total Cartao, como divida quando negativo.
  - Patrimonio em Conta.
- Grid de cards:
  - Cor customizavel.
  - Icone por tipo.
  - Saldo formatado.
  - Badge PF/PJ.
  - Badge "Conta inativa" quando `ativo: false`.
- Botao "Nova Conta" abre modal com todos os campos.
- Editar e excluir via menu dropdown em cada card.
- Botao "Lancar Transacao" em cada card abre modal de transacao com `contaId` preenchido.

## Validacao

- Usar `react-hook-form` e Zod.
- Usar componentes shadcn/ui para modal, inputs, selects, labels e botoes.
- Validar tipo, perfil, nome, instituicao, saldo e cor.
- Nao permitir excluir conta com transacoes vinculadas sem regra explicita.
