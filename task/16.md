# Task 16 - README e Criterios de Aceitacao

## Objetivo

Criar README final com instalacao, comandos, credenciais padrao, modulos disponiveis e criterios de aceite do projeto.

## Quick Start Docker

Docker e o caminho recomendado:

```bash
# 1. Clone e entre no diretorio
git clone <repo> && cd projeto

# 2. Configure a API Key da Anthropic, opcional
echo 'ANTHROPIC_API_KEY=sk-ant-...' >> .env

# 3. Suba tudo
pnpm run docker:up

# 4. Acesse
# http://localhost:3000
# Login: admin@projeto.local / admin123
```

## Quick Start local

```bash
# Requer: Node 20+ e PostgreSQL 15+ local
cp .env .env.local
# Editar .env.local: DATABASE_URL deve apontar para localhost:5432
pnpm install
pnpm exec prisma migrate dev --name init
pnpm run db:seed
pnpm run dev
```

## Comandos uteis

| Comando | Descricao |
| --- | --- |
| `pnpm run docker:up` | Sobe tudo com build |
| `pnpm run docker:down` | Para os containers |
| `pnpm run docker:reset` | Apaga volumes e recria do zero |
| `pnpm run docker:db:studio` | Abre Prisma Studio no container |
| `pnpm run docker:logs` | Logs da aplicacao em tempo real |

## Criterios de aceitacao

O projeto so esta concluido quando todos os itens abaixo passarem:

| # | Criterio | Como verificar |
| --- | --- | --- |
| 1 | `pnpm run docker:up` executa sem erros | Terminal nao exibe erros apos build |
| 2 | App disponivel em `http://localhost:3000` | Pagina de login carrega |
| 3 | Login funciona | `admin@projeto.local` / `admin123` autentica |
| 4 | Dashboard exibe dados reais | KPIs mostram valores calculados do seed |
| 5 | Modulo de Contas funciona | 4 contas do seed aparecem e modal salva |
| 6 | Import CSV Nubank funciona | Upload de CSV importa transacoes |
| 7 | Categorizacao por IA funciona | Com API key, retorna categorias |
| 8 | Modulo Empresarial exibe DRE | Empresa seed aparece com DRE calculado |
| 9 | Modulo de Investimentos exibe carteira | 5 posicoes do seed com P&L |
| 10 | Sem erros de TypeScript | `pnpm run typecheck` passa |
| 11 | Sem erros de console no browser | Console sem erros nas paginas principais |
| 12 | `pnpm run docker:reset` funciona | Reset recria volume, migrations e seed |
