# Task 06 - Layout Base

## Objetivo

Criar a casca navegavel do app com layout raiz, login, sidebar, header e layout protegido.

## Arquivos principais

- `projeto/frontend/src/app/layout.tsx`
- `projeto/frontend/src/app/(auth)/login/page.tsx`
- `projeto/frontend/src/components/layout/Sidebar.tsx`
- `projeto/frontend/src/components/layout/Header.tsx`
- `projeto/frontend/src/app/(app)/layout.tsx`

## Layout raiz

Em `projeto/frontend/src/app/layout.tsx`:

- Importar fontes via `next/font/google`: `Sora` e `DM Sans`.
- Aplicar variaveis CSS `--font-sora` e `--font-dm-sans`.
- Incluir `<Toaster />` do Sonner com `position="bottom-right"`.
- Incluir provider de sessao quando necessario.
- Definir metadata: titulo, descricao e viewport.

## Login

Em `projeto/frontend/src/app/(auth)/login/page.tsx`:

- Verificar sessao no servidor e redirecionar para `/dashboard` se autenticado.
- Criar design dark premium com gradiente sutil no background.
- Exibir logo e nome do produto.
- Usar `react-hook-form` e Zod.
- Validar email obrigatorio e senha com minimo de 6 caracteres.
- Chamar `signIn("credentials", { email, password, redirect: false })`.
- Tratar erro com toast.
- Implementar icone de mostrar/ocultar senha.

## Sidebar

Em `projeto/frontend/src/components/layout/Sidebar.tsx`:

- Largura fixa de 240px no desktop.
- Overlay em mobile.
- Logo `Financas 360`.
- Grupos:
  - VISAO GERAL: Dashboard.
  - FINANCAS: Contas, Transacoes, Metas.
  - EMPRESARIAL: Painel Empresarial.
  - PATRIMONIO: Investimentos.
  - SISTEMA: Configuracoes.
- Item ativo com `--accent-blue`.
- Avatar, nome do usuario e logout no rodape.
- Hamburger em mobile com `useState`.

## Header

Em `projeto/frontend/src/components/layout/Header.tsx`:

- Titulo da pagina atual via `usePathname`.
- Seletor de periodo: Mes Atual, Mes Anterior, Trimestre, Ano, Customizado.
- Seletor de perfil: Todos, PF, PJ.
- Botao de notificacoes com badge numerico.

## Layout protegido

Em `projeto/frontend/src/app/(app)/layout.tsx`:

- Usar `getServerSession`.
- Redirecionar para `/login` se nao autenticado.
- Renderizar `<Sidebar />`, `<Header />` e `<main>{children}</main>`.
- Passar periodo e perfil como `searchParams` para paginas filhas quando aplicavel.

## Checklist

- [ ] Usuario nao autenticado vai para `/login`.
- [ ] Usuario autenticado acessa `/dashboard`.
- [ ] Sidebar e header aparecem nas paginas protegidas.
- [ ] Layout mobile nao quebra.
- [ ] Textos de interface estao em portugues do Brasil.
