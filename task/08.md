# Task 08 - Dashboard

## Objetivo

Implementar `/dashboard` com KPIs, graficos, insights e alertas calculados a partir dos dados reais do seed.

## Pagina

Arquivo:

- `projeto/frontend/src/app/(app)/dashboard/page.tsx`

Requisitos:

- Server Component.
- Ler `searchParams` para periodo e perfil.
- Buscar dados no backend para dashboard resumo e evolucao.
- Passar dados aos Client Components por props.

## Componentes

Criar em `frontend/src/components/dashboard/`:

| Componente | Descricao |
| --- | --- |
| `KPICard.tsx` | Titulo, valor formatado, variacao percentual, icone lucide e cor por prop |
| `PatrimonioCard.tsx` | Patrimonio liquido: contas + investimentos - dividas |
| `FluxoCaixaChart.tsx` | `BarChart` receitas vs despesas por mes, ultimos 6 meses |
| `EvolucaoPatrimonioChart.tsx` | `AreaChart` patrimonio total por mes, 12 meses |
| `CategoriasDespesaChart.tsx` | Donut top 6 categorias de despesa |
| `InsightCard.tsx` | Lista de insights da IA com loading skeleton |
| `AlertasCard.tsx` | Contas a vencer, metas proximas e gastos acima da media |

## Layout

- Grid de 4 colunas para KPIs.
- Area de 2 colunas para graficos e insights/alertas.
- Area de 3 colunas para graficos secundarios.
- Deve funcionar com listas vazias.
