# Task 07 - API Routes

## Objetivo

Implementar todas as rotas de API protegidas e validadas no backend em `backend/src/`.

## Padroes obrigatorios

Todas as rotas devem:

1. Verificar sessao e retornar `401` se nao autenticado.
2. Filtrar sempre por `userId`.
3. Validar body e filtros com Zod.
4. Validar datas com Day.js e documentos brasileiros com biblioteca especializada quando existirem no payload.
5. Retornar `400` para payload invalido.
6. Tratar erros Prisma com `409` para conflitos e `404` para recurso inexistente ou sem ownership.
7. Retornar sucesso em JSON no formato `{ data, meta? }`.
8. Ter ordenacao explicita em listagens.

## Rotas

| Rota | Metodos | Observacoes |
| --- | --- | --- |
| `/api/contas` | GET, POST | GET lista com saldo calculado; POST valida tipo e perfil |
| `/api/contas/[id]` | GET, PUT, DELETE | DELETE verifica transacoes vinculadas |
| `/api/transacoes` | GET, POST | Filtros: startDate, endDate, tipo, categoria, contaId, perfil, search, page, limit |
| `/api/transacoes/[id]` | GET, PUT, DELETE | CRUD protegido |
| `/api/transacoes/import-csv` | POST | Recebe `TransacaoBruta[]`, deduplica e salva em batch |
| `/api/transacoes/categorizar-ia` | POST | Recebe `ids[]`, chama IA e atualiza categorias |
| `/api/investimentos` | GET, POST | CRUD base |
| `/api/investimentos/[id]` | GET, PUT, DELETE | CRUD protegido |
| `/api/investimentos/[id]/aportes` | GET, POST | POST recalcula precoMedio e valorInvestido |
| `/api/metas` | GET, POST | CRUD base |
| `/api/metas/[id]` | GET, PUT, DELETE | CRUD protegido |
| `/api/empresas` | GET, POST | CRUD base |
| `/api/empresas/[id]` | GET, PUT, DELETE | CRUD protegido; CNPJ deve ser valido |
| `/api/dashboard/resumo` | GET | KPIs calculados do periodo selecionado |
| `/api/dashboard/evolucao` | GET | Patrimonio por mes dos ultimos 12 meses |
| `/api/ai/insights` | GET | Agrega dados e chama `gerarInsights` |

## Checklist

- [ ] Toda rota protegida valida sessao.
- [ ] Toda consulta filtra `userId`.
- [ ] Payload invalido retorna `400`.
- [ ] Datas invalidas retornam `400`.
- [ ] CNPJ invalido retorna `400`.
- [ ] Recurso inexistente ou sem ownership retorna `404`.
- [ ] Conflitos retornam `409`.
- [ ] Nenhuma rota retorna dados de outro usuario.
