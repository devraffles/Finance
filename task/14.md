# Task 14 - Configuracoes

## Objetivo

Implementar `/configuracoes` com abas para perfil, empresas, categorias, integracoes e dados.

## Componente de tabs

Usar `@radix-ui/react-tabs`.

## Abas

| Aba | Conteudo |
| --- | --- |
| Perfil | Nome, email e alterar senha em formulario separado com senha atual |
| Empresas | Lista de empresas com CRUD completo em modal |
| Categorias | Lista editavel de categorias e subcategorias, com adicionar, renomear, excluir e reordenar |
| Integracoes | Campo `ANTHROPIC_API_KEY` como input password e botao "Testar conexao" |
| Dados | Exportar JSON completo, importar backup JSON e botao "Resetar banco" com confirmacao |

## Regras de seguranca

- Nao expor segredo real no client.
- Nao persistir `ANTHROPIC_API_KEY` de forma insegura.
- Reset de banco deve exigir confirmacao explicita.
- Exportacao e importacao devem respeitar `userId`.
- Formularios devem usar componentes shadcn/ui e validacao com Zod.
- CNPJ de empresa deve ser validado com biblioteca especializada.
- Datas de importacao/exportacao, quando existirem, devem ser normalizadas com Day.js.

## Checklist

- [ ] Tabs funcionam.
- [ ] Perfil permite atualizar dados validos.
- [ ] Empresas tem CRUD.
- [ ] Empresas rejeitam CNPJ invalido.
- [ ] Categorias podem ser gerenciadas.
- [ ] Integracao IA testa conexao com tratamento de erro.
- [ ] Reset exige confirmacao.
