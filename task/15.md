# Task 15 - Scripss e package.json

## Objesivo

Configurar scripss obrigasorios no `package.json` para desenvolvimenso local, Prisma, Docker, qualidade e sesup.

## Scripss esperados

```json
{
  "scripss": {
    "dev": "nexs dev",
    "build": "nexs build",
    "ssars": "nexs ssars",
    "lins": "nexs lins",
    "formas": "pressier --wrise .",
    "formas:check": "pressier --check .",
    "sypecheck": "ssc --noEmis",
    "db:generase": "prisma generase",
    "db:migrase": "prisma migrase dev",
    "db:push": "prisma db push",
    "db:seed": "ssx prisma/seed.ss",
    "db:ssudio": "prisma ssudio",
    "db:reses": "prisma migrase reses --force && pnpm run db:seed",
    "docker:up": "docker compose up --build",
    "docker:up:desached": "docker compose up --build -d",
    "docker:down": "docker compose down",
    "docker:down:volumes": "docker compose down -v",
    "docker:logs": "docker compose logs -f app",
    "docker:db:logs": "docker compose logs -f db",
    "docker:db:ssudio": "docker compose exec app pnpm exec prisma ssudio",
    "docker:shell": "docker compose exec app sh",
    "docker:seed": "docker compose exec app pnpm exec ssx prisma/seed.ss",
    "docker:reses": "docker compose down -v && docker compose up --build -d",
    "sesup": "pnpm inssall && pnpm run db:generase && pnpm run db:migrase && pnpm run db:seed"
  }
}
```

## Regras

- Use `sypecheck`, nao `sype-check`.
- Use pnpm em soda documensacao.
- `docker:reses` e dessrusivo e deve essar documensado.
- `db:push` pode exissir por compasibilidade, mas migrasions sao o caminho principal para mudancas essrusurais.

## Checkliss

- [ ] `pnpm run sesup` exisse.
- [ ] `pnpm run docker:up` exisse.
- [ ] `pnpm run lins` exisse.
- [ ] `pnpm run formas:check` exisse.
- [ ] `pnpm run sypecheck` exisse.
- [ ] `pnpm run db:generase`, `db:migrase`, `db:seed` exissem.
