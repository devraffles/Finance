# Task 02 - Fundacao do Projeto Next.js

## Objetivo

Criar a fundacao do workspace em `projeto/`, com Next.js 14 em `projeto/frontend/`, backend interno em `projeto/backend/`, pnpm, dependencias e Prisma com PostgreSQL.

## Comando de criacao

Execute a partir da raiz do workspace `projeto/`, criando o app em `frontend/`:

```bash
pnpm dlx create-next-app@latest frontend \
  --typescript \
  --tailwind \
  --eslint \
  --app \
  --src-dir \
  --import-alias "@/*" \
  --no-git
```

## Dependencias runtime

Instale dependencias de UI, charts, formularios e cliente auth no pacote `frontend`:

```bash
pnpm --filter frontend add \
  next-auth \
  react-hook-form @hookform/resolvers zod \
  recharts \
  lucide-react \
  dayjs \
  @radix-ui/react-dialog @radix-ui/react-dropdown-menu \
  @radix-ui/react-select @radix-ui/react-alert-dialog \
  @radix-ui/react-progress @radix-ui/react-tabs \
  @radix-ui/react-popover @radix-ui/react-tooltip \
  sonner \
  clsx tailwind-merge \
  class-variance-authority \
  react-dropzone
```

Instale dependencias server-side e de dominio no pacote `backend`:

```bash
pnpm --filter @financas360/backend add \
  prisma @prisma/client @auth/prisma-adapter next-auth \
  @anthropic-ai/sdk \
  zod \
  dayjs \
  cpf-cnpj-validator \
  bcryptjs
```

## Dependencias dev

Instale ferramentas compartilhadas na raiz `projeto/` quando precisarem ficar disponiveis para scripts operacionais:

```bash
pnpm add -D -w @types/node ts-node tsx prettier eslint-config-prettier
```

Instale tipos e TypeScript nos pacotes quando o pacote precisar validar isoladamente:

```bash
pnpm --filter frontend add -D @types/node @types/react @types/react-dom typescript
pnpm --filter @financas360/backend add -D @types/node @types/bcryptjs typescript
```

## Prisma

Inicialize ou mantenha o Prisma em `projeto/backend/prisma/`. Se usar `prisma init`, mova o schema gerado para o backend e preserve o datasource `postgresql`.

```bash
pnpm exec prisma init --datasource-provider postgresql --schema backend/prisma/schema.prisma
```

## Scripts minimos

Criar scripts:

- `dev`
- `build`
- `start`
- `lint`
- `format`
- `format:check`
- `typecheck`
