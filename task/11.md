# Task 11 - Modulo de Investimentos

## Objetivo

Implementar `/investimentos` com KPIs, tabela de posicoes, graficos e modais de cadastro/aportes.

## KPIs

No topo da pagina:

- Total Investido.
- Valor Atual com variacao absoluta.
- Rentabilidade Total em R$ e percentual.

## Tabela de posicoes

| Coluna | Formato |
| --- | --- |
| Nome | Texto |
| Tipo | Badge colorido por tipo |
| Corretora | Texto |
| Qtd | Numero |
| Preco Medio | R$ |
| Preco Atual | R$ |
| Valor Investido | R$ |
| Valor Atual | R$ com variacao |
| P&L | R$ e percentual |
| % Carteira | Barra de progresso |

## Graficos

- Donut de alocacao por tipo.
- Linha de rentabilidade acumulada mensal.

## Modais

- Cadastrar posicao:
  - Campos condicionais por tipo.
  - Renda fixa mostra taxa, indexador e vencimento.
  - Acoes mostra quantidade e preco medio.
- Historico de aportes:
  - Tabela.
  - `BarChart` de valor por data.
  - Totalizadores.

## Checklist

- [ ] 5 posicoes do seed aparecem.
- [ ] P&L e rentabilidade sao calculados.
- [ ] Aportes recalculam preco medio e valor investido.
- [ ] Estados vazio, loading e erro existem.
- [ ] Nenhum dado de outro usuario aparece.
