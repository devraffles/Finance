# Task 18 - Base de configuracao para MFA e Login Google

## Objetivo

Preparar dependencias, configuracao de ambiente e contratos para MFA e Google OAuth, sem quebrar o login atual por e-mail e senha.

## Tarefas

1. Confirmar na documentacao oficial do Better Auth a extensao compativel para Google OAuth, autenticacao em dois fatores e TOTP antes de escolher a API de integracao.
2. Instalar somente as dependencias necessarias nos workspaces corretos, usando `pnpm` e mantendo o backend como o unico local de segredos e integracoes de autenticacao.
3. Atualizar `projeto/.env.example` com placeholders vazios e descricoes para:
   - `GOOGLE_CLIENT_ID`;
   - `GOOGLE_CLIENT_SECRET`;
   - URL publica/base da aplicacao usada nos callbacks;
   - remetente e provedor de e-mail;
   - chave de criptografia para segredos MFA, se exigida pela implementacao.
4. Atualizar a configuracao server-side do Better Auth em `backend/src/lib/auth.ts` para aceitar Google OAuth e os fluxos de MFA planejados, preservando email/senha e o adapter Prisma.
5. Criar uma interface tipada de entrega de e-mail no backend. A implementacao deve permitir troca de provedor sem expor detalhes no frontend.
6. Documentar no README a configuracao do OAuth no Google Cloud, incluindo a URL de callback local. Nao incluir valores reais, capturas com segredos ou tokens.
7. Definir tipos e constantes no backend para metodos MFA, estados do desafio e eventos de auditoria, usando TypeScript estrito e sem `any`.

## Regras

- Componentes React nao podem importar SDKs, segredos ou configuracao do Better Auth.
- O login Google deve solicitar apenas escopos essenciais de perfil/e-mail.
- A ausencia de configuracao do Google ou de e-mail deve resultar em estado controlado, nunca em erro de build ou segredos expostos.
- Validar variaveis de ambiente no backend com Zod.

## Checklist

- [ ] Dependencias foram instaladas com `pnpm` nos pacotes corretos.
- [ ] `.env.example` contem apenas placeholders seguros.
- [ ] Login por e-mail e senha continua configurado.
- [ ] O backend possui contratos tipados para MFA, e-mail e auditoria.
- [ ] README explica callback Google e configuracao local sem segredos.
- [ ] `pnpm run lint`, `pnpm run format:check`, `pnpm run typecheck` e `pnpm run build` passam.
