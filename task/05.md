# Task 05 - Configuracoes Base

## Objetivo

Criar a infraestrutura base de aplicacao: Prisma, autenticacao, wrapper Gemini, utilitarios e tipos de dominio.

## Arquivos

- `projeto/backend/src/lib/prisma.ts`
- `projeto/backend/src/lib/auth.ts`
- `projeto/backend/src/lib/gemini.ts`
- `projeto/frontend/src/lib/utils.ts`
- `projeto/backend/src/types/financas.ts`

## `backend/src/lib/prisma.ts`

Implementar singleton do `PrismaClient` com hot reload seguro para Next.js.

## `backend/src/lib/auth.ts`

Implementar NextAuth com Credentials Provider:

- Validar email e senha com `bcrypt.compare`.
- Sessao JWT com `id`, `name` e `email`.
- Callbacks `session` e `jwt` para propagar `user.id`.
- Exportar `authOptions` e helper `getSession()` para Server Components.

## `backend/src/lib/gemini.ts`

Exportar:

```ts
export async function callGemini(
  prompt: string,
  systemPrompt?: string,
): Promise<string>;

export async function categorizarTransacoes(
  transacoes: TransacaoBruta[],
): Promise<CategorizacaoResult[]>;

export async function gerarInsights(
  dados: DadosFinanceiros,
): Promise<Insight[]>;
```

Regras:

- Usar `gemini-2.5-flash` para categorizacao.
- Usar `gemini-2.5-pro` para insights.
- Se `GOOGLE_GENERATIVE_AI_API_KEY` estiver ausente, retornar estado controlado sem quebrar o app.
- Usar timeout de 30s com `AbortController`.
