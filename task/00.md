# Task 00 - Pre-requisitos e Estrutura Raiz

## Objetivo

Preparar a base inicial do projeto `projeto/`, confirmando prerequisitos de Docker e criando a estrutura raiz esperada para a aplicacao Financas 360.

## Contexto obrigatorio

Antes de implementar, leia:

- `AGENTS.md`
- `.codex/tasks.md`
- `.codex/rules/general.md`
- `.codex/rules/docker.md`
- `.codex/rules/database.md`
- `prompt-projeto-codex.md`

Nao use a pasta `app/` como stack alvo. Ela pode servir apenas como referencia seletiva visual ou de componentes.

## Stack e infraestrutura

- Next.js 14 com App Router e TypeScript.
- PostgreSQL com Prisma via Docker Compose.
- Tailwind CSS com componentes no estilo shadcn/ui.
- pnpm como package manager obrigatorio.

## Regras

- Nao coloque segredos reais em arquivos versionaveis.
- `.env` e para Docker Compose.
- `.env.local` e para execucao local fora do Docker.
- Backend deve ficar em `backend/`; frontend deve ficar em `frontend/`.
- Se `projeto/` ainda nao existir, crie apenas quando a implementacao do app for explicitamente solicitada.
