# Task 01 - Docker

## Objetivo

Criar a infraestrutura Docker oficial do Financas 360 com servicos `app` e `db`, usando PostgreSQL 16 e pnpm.

## Arquivos

- `projeto/docker-compose.yml`
- `projeto/docker-compose.override.yml`
- `projeto/Dockerfile`
- `projeto/.dockerignore`
- `projeto/.env`
- `projeto/.env.example`

## `docker-compose.yml`

```yaml
version: "3.9"

services:
  db:
    image: postgres:16-alpine
    container_name: projeto_db
    restart: unless-stopped
    environment:
      POSTGRES_USER: projeto
      POSTGRES_PASSWORD: projetopass
      POSTGRES_DB: projeto
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U projeto"]
      interval: 5s
      timeout: 5s
      retries: 10

  app:
    build:
      context: .
      dockerfile: Dockerfile
      target: development
    container_name: projeto_app
    restart: unless-stopped
    depends_on:
      db:
        condition: service_healthy
    env_file:
      - .env
    ports:
      - "3000:3000"
    volumes:
      - .:/app
      - /app/node_modules
      - /app/.next
    command: sh -c "corepack enable && pnpm exec prisma migrate deploy && pnpm exec prisma db seed && pnpm run dev"

volumes:
  postgres_data:
```

## `docker-compose.override.yml`

```yaml
version: "3.9"

services:
  app:
    environment:
      - NODE_ENV=development
```

## `Dockerfile`

```dockerfile
FROM node:20-alpine AS base
WORKDIR /app
RUN apk add --no-cache libc6-compat openssl
RUN corepack enable

FROM base AS deps
COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile

FROM base AS development
COPY --from=deps /app/node_modules ./node_modules
COPY . .
EXPOSE 3000
ENV PORT 3000
ENV HOSTNAME "0.0.0.0"
ENV NEXT_TELEMETRY_DISABLED 1

FROM base AS builder
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN pnpm exec prisma generate
ENV NEXT_TELEMETRY_DISABLED 1
RUN pnpm run build

FROM base AS production
ENV NODE_ENV production
ENV NEXT_TELEMETRY_DISABLED 1
RUN addgroup --system --gid 1001 nodejs && adduser --system --uid 1001 nextjs
COPY --from=builder /app/public ./public
COPY --from=builder --chown=nextjs:nodejs /app/.next/standalone ./
COPY --from=builder --chown=nextjs:nodejs /app/.next/static ./.next/static
COPY --from=builder /app/prisma ./prisma
COPY --from=builder /app/node_modules/.prisma ./node_modules/.prisma
USER nextjs
EXPOSE 3000
ENV PORT 3000
ENV HOSTNAME "0.0.0.0"
CMD ["node", "server.js"]
```

## `.dockerignore`

```text
node_modules
.next
.git
*.log
.env.local
dist
coverage
```

## Variaveis

`.env` deve apontar `DATABASE_URL` para `db:5432`.

`.env.local` deve apontar `DATABASE_URL` para `localhost:5432`.
